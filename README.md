# Sampreet Ghosh Portfolio

A clean, light React + Vite portfolio redesigned from the original portfolio direction.

## Design direction
- Light blue + orange visual system
- Editorial / hand-crafted layout instead of generic AI-dashboard styling
- Asymmetric cards, small notes, thin borders and subtle paper-like texture
- Responsive mobile navigation
- Project previews built with HTML/CSS so the site does not depend on stock or AI-generated hero artwork

## Current content
- B.Tech CSE, Netaji Subhash Engineering College, 2023–2027
- 7.8 CGPA till 6th semester
- 290+ DSA problems
- ResumeAI
- PocketPath
- CareerCraft
- InterviewForge
- Smart India Hackathon, GirlScript and Hacktoberfest highlights

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before deploying
1. Add your current `resume.pdf` to `public/` if you want a resume download button later.
2. Replace any project live-demo URLs if a newer deployment exists.
3. Update the email/social links in the components if needed.
