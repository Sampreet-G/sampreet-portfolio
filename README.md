# Sampreet Ghosh — Portfolio

> Personal portfolio website for Sampreet Ghosh, a B.Tech CSE student focused on frontend, full-stack web development, and AI-powered applications.

## ✨ Overview

This portfolio showcases my projects, technical skills, experience, and achievements while keeping the visual style clean, modern, and personal.

The design takes inspiration from editorial portfolio layouts, soft blue/orange accents, rounded cards, and subtle hand-crafted details without relying on heavy gradients or generic AI-dashboard aesthetics.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Sampreet-G/sampreet-portfolio.git
cd sampreet-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## 📦 Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
